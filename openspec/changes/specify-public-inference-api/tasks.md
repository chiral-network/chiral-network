Each chat probe goes to `/apply-template` with exactly the body that generation receives, then to `/tokenize`. Completion prompts are dispatched as the engine's own token IDs, and no `echo`, `logprobs` or `top_logprobs` reaches the engine. An embedding model is probed with a two-input batch in `float` and in `base64`, as token IDs, and its dimension is returned.
